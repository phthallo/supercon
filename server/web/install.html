install.

Put the canvas on your own Supercon badge! You need Chrome or Edge on a computer and a USB-C cable.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

wifi

Saved on your badge only. It joins whichever network is in range. Networks with a sign-in page won't work, but a phone hotspot will.

add ink

Keeps everything on your badge. Redraws take about 40s.

full image

Erases your badge and installs the stock apps plus ink, with faster redraws (about 5s).

  1. needs Chrome or Edge needs https

after installing

Press the menu buttons to pick Ink, then press A. The badge checks the canvas every minute.

host your own

Want a canvas for just your friends? Run your own copy of this site. Badges installed from your site show your canvas.

  1. Fork phthallo/supercon.
  2. Deploy server/ on any host that runs containers (Coolify, Fly.io, a VPS). docker compose up in server/ starts it with a Postgres database.
  3. Serve it over https. The flasher and USB access only work on secure pages.
  4. Set the environment variables below.
  5. Open /install on your site and install as above.
DATABASE_URLa postgres:// URL. The compose file sets it.
ADMIN_PASSWORDpassword for /admin, where you add text and images. Admin is off without it.
PAINT_COOLDOWNwait between paints, like 30s. 0s turns it off.
WIFI_SSID, WIFI_PASSWORDa network to prefill on this page.
TRUSTED_PROXY_HEADERheader holding the visitor's IP behind a proxy. Defaults to X-Forwarded-For in the Docker image.

To change the badge app or the full image, edit the repo and run .venv/bin/python tools/build.py supercon ink --release, then redeploy. The README covers setting up the tools.
